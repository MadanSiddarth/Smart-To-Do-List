# Smart To-Do List

A responsive task management web application built using HTML, CSS, and JavaScript. It helps users organize daily tasks, set deadlines, assign priorities, and track their progress.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by All, Active, and Completed
- Assign due dates to tasks
- Set Low, Medium, and High priorities
- Save tasks using browser localStorage
- Responsive interface for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser DOM API
- localStorage

## Getting Started

1. Clone this repository or download the ZIP file.
2. Open `index.html` in a modern web browser.
3. Add tasks, select due dates and priorities, and manage your task list.

No additional packages are required.
